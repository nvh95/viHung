Learn vi and vim by playing

viHung is a free, interactive vi trainer. You type real keystrokes into a simulated Linux server terminal and get instant feedback, so you stop getting stuck in vi.

12 lessons, 46 drills

  1. Get out alive: how to exit vi with :q and :q!
  2. Normal mode and Insert mode
  3. Saving and quitting: :w, :wq, :x, ZZ
  4. Moving with h, j, k, l and counts
  5. Jumping by word, line and file: w, b, e, 0, $, gg, G, :42
  6. Deleting: x, dw, dd, D
  7. Undo and redo: u and Ctrl-R
  8. More ways into Insert mode: a, A, I, o, O
  9. Copy and paste: yy, p, P
  10. Search: /, ?, n, N
  11. Replace: r, cw, :%s/old/new/g
  12. Server missions: sudo vi, swap files (E325), frozen terminal (Ctrl-S), suspended vi (Ctrl-Z)

Plus an arcade with timed games, a key quiz and a printable key card.
